# Into The Wild — Eco-Adventure Wildlife Park Website

A full-stack marketing website for a fictional eco-adventure wildlife park.

## Technologies Used
- HTML, CSS, JavaScript
- Node.js, Express
- EJS (templating)
- SQLite3

## How to Run
1. Unzip the project folder
2. Open in VSCode
3. In the terminal run: npm install
4. In the terminal run: node index.mjs
5. Open your browser and go to: http://localhost:5000

## Pages
- Home
- Habitats
- Opening Times
- Contact
- FAQ
